## 2024-05-18 - Improve Global Keyboard Focus Visibility
**Learning:** The application had `outline: none;` on inputs and lacked explicit keyboard focus rings on interactive elements, making it difficult for keyboard users to track focus. When disabling default outlines, using `outline: 2px solid transparent;` instead of `outline: none;` or `outline: transparent;` (which defaults to style none) ensures the outline still renders in Windows High Contrast Mode. Additionally, modern browsers curve the outline to match the element's existing border-radius, so adding `border-radius` to a global `:focus-visible` rule is unnecessary and causes elements to visually mutate shape upon focus.
**Action:** Changed `outline: none;` to `outline: 2px solid transparent;` for WHCM support and implemented a global `:focus-visible` rule using existing design tokens (`var(--accent-blue)`) with an offset to provide a clear focus ring without impacting standard mouse click behavior.
